# ohdo UI v2 와이어프레임 (텍스트 1차 설계)

> **목적**: [feature_catalog.md §13](feature_catalog.md) 의 결정 16건 (D1~D16) 을 반영한 새 UI 의 화면 구성 / 인터랙션 / 키보드 흐름. Excalidraw/Figma 정식 와이어프레임의 기반.
>
> **마지막 업데이트**: 2026-05-05 (1차 초안)
>
> **베이스 원칙**:
> - **Less chrome, more content** — 현재 UI 의 두꺼운 보더/레이블 정리
> - **Progressive disclosure** — 고급 옵션은 필요 시에만
> - **Keyboard-first** — Ctrl+K palette, 단축키 5종
> - **Web 일관성** — Phase 3 웹 대시보드와 디자인 토큰 공유
> - **Toast over modal** — confirm/destructive 만 modal

### 1.1 영역별 설명

| 영역 | 위치 | D 참조 | 주요 변화 |
|------|------|--------|-----------|
| **탭바** | 최상단 | D4 | 세션마다 탭 1개. 브라우저 스타일. + 버튼 = 새 세션. 우측에 search/settings/profile 아이콘. |
| **액션바** | 탭바 아래 | D7, D11 | 전체 실행 / Stop / 커널 재시작 / AI 엔진 드롭다운 / 세션 default wait. |
| **사이드바** | 좌측 (collapsible) | D4 | 세션 목록 + 새 세션. 토글 가능 (Ctrl+B 같은 단축키 추후). |
| **메인 뷰** | 중앙 (D1+D3) | D1, D3 | **단일 스크롤**. 라이브러리 → Initial → Step 카드들 세로 나열. 각 카드 안에 사용자 요청 + AI 설명 + 코드 + 캡처/요소 통합. |
| **입력 영역** | 메인 뷰 하단 (sticky) | D6 | 요소 칩 (선택 시) + 입력창 + 캡처/요소픽/전송. 입력창 위에 활성 칩들 표시. |
| **상태바** | 최하단 | D5 | 우측 ` 아이콘 클릭 또는 Ctrl+\` 으로 콘솔 토글. |
| **콘솔** | 토글 시 하단 25% | D5 | VS Code 스타일. 4 탭 (전체/프롬프트/실행/AI) 유지. |

### 1.2 현재 UI 와의 차이

| 영역 | 현재 (v1) | v2 | 사유 |
|------|-----------|----|------|
| 코드 뷰 ↔ 블럭 뷰 | QTabWidget 2개 탭 | **단일 통합 뷰** (블럭 베이스) | D1 — tab 전환 학습 비용 + desync 4중 안전장치 부담 ↓ |
| 채팅 ↔ 코드 | 좌우 분리 | **step 카드 안에 인라인** | D3 — 어떤 요청이 어떤 코드 만들었는지 시각 매칭 |
| 세션 | 좌측 목록만 | **탭 + 좌측 목록 (collapsible)** | D4 — 다중 세션 동시 작업 |
| 콘솔 | 항상 하단 25% | **토글 (Ctrl+\`)** | D5 — 평소엔 화면 확보 |
| 요소 칩 | 입력창 위 | **입력창 위 (활성) + step 카드 안 (저장)** | D6 — 컨텍스트 추적 |

### 2.1 카드 구성 요소 (위 → 아래)

| 요소 | 표시 조건 | 동작 |
|------|-----------|------|
| **헤더** | 항상 | 펼침/접힘 (▼/▶), 제목, 상태 (✅/❌/🔄), 메트릭 (시간·토큰) |
| **사용자 요청** | step 에 user_request 있을 때 | 읽기 전용 텍스트. 클릭 시 수정 모드 (재실행 트리거 옵션) |
| **AI 설명** | step 에 ai_description 있을 때 | 기본 접힘 (옵션 펼침). 긴 응답을 코드와 분리 |
| **요소 칩 + 캡처** | 첨부 있을 때 | 클릭 시 큰 미리보기. ✕ 로 제거 |
| **코드** | 항상 | 코드 블럭. ✏ 수정 모드 / Diff 토글 |
| **푸터** | 항상 | wait override / 실행 / 단독 / 삭제 |

### 2.2 인터랙션

- **사용자 요청 영역 클릭** → 인라인 편집 모드 → 저장 시 "이 요청으로 다시 생성?" 토스트 (D9). Yes 면 AI 재호출.
- **AI 설명 ▼ 펼침** → ai_description 전체 표시. 기본은 1~2 줄 미리보기.
- **코드 영역 ✏** → 인라인 편집 (현재 BlockCard 패턴 동일). 저장 시 manually_edited=True.
- **코드 영역 Diff** → 이전 step 과 비교 뷰 토글.
- **wait 드롭다운** → 빠른 변경 (현재 SpinBox 대신 드롭다운으로 단순화: 0/100/500/1000/2000/사용자정의...). 토글이 더 빠른 UX.

### 2.3 라이브러리 / Initial 카드 (간소화)

```
╭─ ▼ 📦 라이브러리 (3 imports + 1 helper) ─── ✏  ▶ 재초기화 ─╮
│ from selenium import webdriver                                │
│ import time                                                   │
│ from selenium.webdriver.common.keys import Keys              │
│                                                               │
│ def find_and_click(driver, selector): ...                    │
╰───────────────────────────────────────────────────────────────╯

╭─ ▼ 🎬 Initial (driver setup) ──────────── ✏  ⏯ 단독 ─────╮
│ options = webdriver.ChromeOptions()                          │
│ options.add_argument('--start-maximized')                    │
│ driver = webdriver.Chrome(options=options)                   │
│ driver.get("https://naver.com")                              │
╰──────────────────────────────────────────────────────────────╯
```

- 라이브러리 / Initial 은 **사용자 요청 / AI 설명 영역 없음** (자동 추출되는 메타).
- 라이브러리 "▶ 재초기화" = 커널 재시작 (현 동작).
- Initial "⏯ 단독" = Phase 2.5 path. **"여기서 실행" 버튼 제거** (D11).

## 6. Toast 알림 (D9 신규)

```
                                              ┌─────────────────────┐
                                              │ ✅ 세션 저장됨       │
                                              │ '메모장 한글 입력'   │
                                              └─────────────────────┘  ← 우측 하단 floating
                                              ┌─────────────────────┐
                                              │ ⚠ 커널 응답 없음    │
                                              │ 재시작 권장 [재시작]│
                                              └─────────────────────┘
```

- 우하단 stack. 4초 자동 사라짐 (action 있는 토스트는 8초).
- 종류: 성공 (✅) / 경고 (⚠) / 정보 (ℹ) / 에러 (❌).
- destructive (세션 삭제 / 데이터 손실 가능) 만 QMessageBox modal.

3. **D19 — AI 설명 영역 default**: 첫 1~2 줄 preview + ▼ 펼침. 카드 길이 통제.

7. **D23 — Step 카드 reorder**: drag-and-drop + ⬆⬇ 버튼 fallback 둘 다.
8. **D24 — Initial 블럭 표시 조건**: 자동 추출 결과 비어있지 않을 때만 (현재 동작 유지).

10. **D26 — 다크/라이트 토글 위치**: settings 탭 만. 자동 감지 default 라 자주 변경 X.
