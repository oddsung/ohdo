## 왜 Postgres + SQLAlchemy + Alembic

| 후보 | 선택 여부 | 이유 |
|---|---|---|
| **PostgreSQL** | ✅ | Railway 원클릭 프로비저닝. JSONB, 풀텍스트 검색, 확장성. SQLite 는 단일 인스턴스 전제라 Railway 복수 컨테이너 환경에서 위험. |
| **SQLAlchemy 2.0 (async)** | ✅ | Python ORM 사실상 표준. 2.0 은 `async/await` 1급 지원. FastAPI 와 자연스럽게 결합. |
| **Alembic** | ✅ | SQLAlchemy 공식 마이그레이션 도구. "현재 DB 상태 → 목표 스키마" 를 버전 관리. |
| asyncpg | ✅ (드라이버) | `postgresql+asyncpg://` 형식. `psycopg2` 대비 비동기 성능 우수. |
| Tortoise ORM | ❌ | 커뮤니티 규모 작음. |
| Raw SQL | ❌ | Migration 도구가 없으면 스키마 진화 관리 불가. |

## 스키마 (1차)

이 단계에서 만들 테이블 두 개. M1.2 에서 `device_codes` 한 개 더 추가 예정.

### `users`

사용자 계정. M1 에서는 Device Flow 로 로그인한 "사람" 을 나타낸다. 웹 대시보드가 생기면 여기에 이메일·비번·결제 정보 등이 붙는다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `id` | `UUID` | PK, default `gen_random_uuid()` | 사용자 ID |
| `email` | `TEXT` | UNIQUE, NOT NULL | 로그인 식별자 (M1.2 에서 채워짐) |
| `display_name` | `TEXT` | NULL | 표시 이름 (선택) |
| `created_at` | `TIMESTAMPTZ` | NOT NULL, default `now()` | 가입 시각 |
| `updated_at` | `TIMESTAMPTZ` | NOT NULL, default `now()` | 마지막 수정 |

### `agents`

사용자가 설치한 Agent 기기. 한 사람이 여러 PC 에 설치할 수 있으므로 1:N.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `id` | `UUID` | PK, default `gen_random_uuid()` | Agent ID |
| `user_id` | `UUID` | FK → `users.id`, ON DELETE CASCADE | 소유자 |
| `name` | `TEXT` | NULL | 사용자 지정 이름 (예: "사무실 데스크톱") |
| `hostname` | `TEXT` | NULL | M1.5 `agent.hello` 에서 전달받는 기기 호스트명 |
| `platform` | `TEXT` | NULL | 예: `win32` |
| `agent_version` | `TEXT` | NULL | 예: `0.0.1` |
| `last_seen_at` | `TIMESTAMPTZ` | NULL | 마지막 heartbeat/ping 시각 |
| `token_hash` | `TEXT` | NOT NULL | 발급한 장기 토큰의 해시 (원문은 저장 안 함) |
| `revoked_at` | `TIMESTAMPTZ` | NULL | 토큰 폐기 시각. NULL = 유효. |
| `created_at` | `TIMESTAMPTZ` | NOT NULL, default `now()` | 등록 시각 |

인덱스:
- `agents_user_id_idx` (FK 조회)
- `agents_token_hash_idx` (인증 시 빠른 조회)

## DATABASE_URL 주입 경로

Railway 가 Postgres 플러그인을 프로젝트에 붙일 때 같은 프로젝트 안의 다른 서비스(여기선 FastAPI) 에 **자동으로 `DATABASE_URL` 환경변수를 주입** 한다. 형식:

```
postgresql://<user>:<pass>@<host>:<port>/<dbname>
```

SQLAlchemy async 로 쓰려면 접두사를 `postgresql+asyncpg://` 로 바꿔야 한다. `app/config.py` 의 Settings 가 이걸 자동 변환.

로컬 개발: `.env` 에 로컬 Postgres URL 을 두거나, `DATABASE_URL=sqlite+aiosqlite:///./dev.db` 폴백. M1.1 에서는 "코드/마이그레이션이 돌긴 돈다" 가 목표라 SQLite 폴백으로도 OK.

## 마이그레이션 실행 방식

- **로컬 또는 직접 실행**: `alembic upgrade head`
- **Railway 배포 시 자동**: `railway.json` 의 `startCommand` 를 `alembic upgrade head && uvicorn ...` 로 체이닝. 컨테이너 **기동 시점**에 실행되므로 `DATABASE_URL` 등 런타임 환경변수에 접근 가능.
- **Procfile `release:` 를 쓰지 않는 이유**: Railway nixpacks 는 Procfile 의 `release:` 를 docker build 단계(RUN 스텝) 로 변환하여 실행한다. 빌드 시점에는 환경변수·네트워크가 없어 alembic 이 실패한다. Heroku 의 release phase 와 동작이 다름 주의.
- **실패 시**: 기동 시점에 alembic 이 실패하면 uvicorn 도 시작 못하므로 Railway 는 헬스체크 실패로 인식하고 이전 배포를 유지한다.
