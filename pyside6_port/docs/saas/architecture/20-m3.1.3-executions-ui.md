## 백엔드 변경

### 신규 `AuthSubject` 데이터클래스

```python
# packages/backend/app/dependencies.py
@dataclass(frozen=True)
class AuthSubject:
    user_id: uuid.UUID
    agent_id: uuid.UUID | None  # None when authenticated as web user
    kind: str                   # "agent" | "user"
```

### 신규 `current_subject` dep

쿠키 우선, 실패 시 Bearer. 둘 다 실패면 401.

```python
async def current_subject(
    request: Request,
    session: AsyncSession = Depends(get_session),
) -> AuthSubject:
    # 1) try web cookie
    user = await _try_cookie_user(request, session)
    if user is not None:
        return AuthSubject(user_id=user.id, agent_id=None, kind="user")
    # 2) try bearer agent
    agent = await _try_bearer_agent(request, session)
    if agent is not None:
        return AuthSubject(user_id=agent.user_id, agent_id=agent.id, kind="agent")
    raise HTTPException(401, detail={"error": "not_authenticated"})
```

`_try_cookie_user` / `_try_bearer_agent` 는 기존 `current_user` / `current_agent` 의 silent 버전 (None 반환). 기존 두 dep 함수는 그대로 유지 (다른 곳에서 사용 중).

### 라우터 수정

**read-only → `current_subject`** (subject.user_id 로 스코프):
- `GET /v0/executions/{execution_id}`
- `GET /v0/executions`
- `GET /v0/executions/{execution_id}/logs`
- `POST /v0/executions/{execution_id}/cancel`
- `GET /v0/executions/{execution_id}/captures`
- `GET /v0/captures/{capture_id}`

**write/agent-only → `current_agent` 유지** (agent_id 가 row 에 의미있게 들어감):
- `POST /v0/executions` (agent_id 가 row 에 박힘)
- `POST /v0/executions/{execution_id}/captures` (agent 가 업로드 주체)

### 호환성

기존 agent 가 사용하던 GET 들도 같은 `current_subject` 로 통과 → 백엔드 동작 변화 없음 (subject.user_id == 기존 agent.user_id). 기존 agent runner 와 Railway agent 모두 무영향.
