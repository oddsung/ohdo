## 목표

웹 사용자가 자기 실행을 **취소** 하고 **새로 만들 수** 있게 한다. M3.1.3 의 read-only 페이지 위에 두 가지 인터랙션을 추가:

1. 상세 페이지: non-terminal 상태일 때 Cancel 버튼.
2. 대시보드: "+ 새 실행" 링크 → `/executions/new` → session_snapshot 폼 → 제출 → `/executions/[id]` redirect.

M3.1.4 완료 조건:

- 백엔드 `POST /v0/executions` 가 쿠키 사용자도 받게 (`current_subject`). agent 자동 선택 (last_seen_at desc).
- web 사용자가 agent 0개일 때 400 `no_agent_available`.
- 기존 Bearer agent flow 변경 없음 (회귀 0).
- 웹 Cancel 버튼 + 폼 client component, 인증·검증 깔끔히 처리.
- typecheck/build PASS, 코어 회귀 25/25.

## 백엔드 변경

### `POST /v0/executions`

- `current_agent` → `current_subject`.
- 인증된 subject 가 agent 면 (Bearer) → `agent_id = subject.agent_id` (기존 동작).
- 인증된 subject 가 user 면 (cookie) → `Agent` 테이블에서 `user_id == subject.user_id AND revoked_at IS NULL` 중 `last_seen_at` 내림차순 첫번째 선택. 없으면 400 `no_agent_available`.
- `Execution` row 의 `user_id` 는 항상 `subject.user_id`. agent_id 는 위에서 결정.
- WS push 는 결정된 agent_id 의 ws 로 (기존과 동일).

### 다른 라우트는 변경 없음

`POST /v0/executions/{id}/captures` 는 여전히 `current_agent` 만 (web 사용자가 capture 업로드할 일 없음).

### `cancel-button.tsx` 핵심 로직

```typescript
"use client";
export function CancelButton({ executionId, initialStatus }) {
  const [hidden, setHidden] = useState(TERMINAL_STATUSES.has(initialStatus));
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const router = useRouter();

  if (hidden) return null;

  async function handleClick() {
    if (!window.confirm("정말 이 실행을 취소하시겠습니까?")) return;
    setLoading(true);
    setError(null);
    const res = await apiFetch(`/v0/executions/${executionId}/cancel`, { method: "POST" });
    setLoading(false);
    if (res.status === 202) {
      setHidden(true);
      // 1.5초 뒤 server component 재 fetch — 헤더의 status badge 도 cancelled 로 갱신
      setTimeout(() => router.refresh(), 1500);
    } else if (res.status === 409) {
      setError("이미 종료된 실행입니다.");
      setHidden(true);
    } else if (res.status === 503) {
      setError("에이전트 오프라인 — 잠시 후 다시 시도하세요.");
    } else if (res.status === 404) {
      setError("실행을 찾을 수 없습니다.");
    } else {
      setError(`취소 실패 (status=${res.status})`);
    }
  }

  return (
    <div className="flex flex-col items-end gap-1">
      <Button variant="secondary" onClick={handleClick} disabled={loading}>
        {loading ? "취소 중…" : "취소"}
      </Button>
      {error ? <span className="text-xs text-red-700">{error}</span> : null}
    </div>
  );
}
```

### `new-execution-form.tsx` 핵심 로직

```typescript
"use client";
type StepDraft = { code: string };

export function NewExecutionForm() {
  const [sessionId, setSessionId] = useState("");
  const [requirementsText, setRequirementsText] = useState("");
  const [steps, setSteps] = useState<StepDraft[]>([{ code: "" }]);
  const [submitting, setSubmitting] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const router = useRouter();

  async function handleSubmit(e: FormEvent) {
    e.preventDefault();
    setSubmitting(true);
    setError(null);

    const stepsClean = steps
      .map((s, i) => ({ step_id: i + 1, generated_code: s.code }))
      .filter((s) => s.generated_code.trim().length > 0);
    if (stepsClean.length === 0) {
      setError("최소 한 개의 스텝이 필요합니다.");
      setSubmitting(false);
      return;
    }

    const requirements = requirementsText
      .split("\n").map((s) => s.trim()).filter(Boolean);

    const body: any = {
      session_snapshot: {
        session_id: sessionId.trim() || `web-${Date.now()}`,
        steps: stepsClean,
      },
    };
    if (requirements.length > 0) body.session_snapshot.requirements = requirements;

    const res = await apiFetch<{ execution_id: string }>(
      "/v0/executions",
      { method: "POST", body: JSON.stringify(body) },
    );
    setSubmitting(false);

    if (res.status === 201 && res.data) {
      router.push(`/executions/${res.data.execution_id}`);
    } else if (res.status === 400) {
      const code = (res.data as any)?.detail?.error;
      if (code === "no_agent_available") {
        setError("등록된 agent 가 없습니다. 먼저 agent 를 Sign In 하세요.");
      } else {
        setError(`요청 실패: ${code ?? JSON.stringify((res.data as any)?.detail)}`);
      }
    } else if (res.status === 422) {
      setError("입력 형식 오류 (from_step/to_step 1 이상이어야 함 등).");
    } else {
      setError(`제출 실패 (status=${res.status})`);
    }
  }

  return (
    <form onSubmit={handleSubmit} className="space-y-6">
      ...session_id, requirements, steps 동적 리스트, [+ 스텝 추가], submit
    </form>
  );
}
```

### 백엔드 e2e (로컬)

| # | 시나리오 | 결과 |
|---|---|---|
| C1 | cookie 로 POST /v0/executions (user 가 agent 1개 가짐) | 201, agent_id 가 그 agent 로 |
| C2 | cookie 로 POST /v0/executions (user 가 agent 0개) | 400 `no_agent_available` |
| C3 | cookie 로 POST /v0/executions (user 가 agent 여러개, 그중 하나만 last_seen_at 이 최근) | 201, 가장 최근 agent 선택됨 |
| C4 | revoked_at 만 있는 agent 가 있을 때 | 400 (revoked agent 는 제외) |
| C5 | Bearer agent 로 POST | 기존 그대로 (agent 자기 자신 사용) |

### 웹 (수동 브라우저)

1. dashboard → "+ 새 실행" 클릭 → /executions/new
2. session_id 비우고 단일 스텝 `print('from web form')` → 제출
3. /executions/[id] 자동 이동 → 진행 상황 polling 으로 관찰 → completed
4. 진행 중인 새 실행 (예: `time.sleep(20)`) 만들고 즉시 상세 진입 → 헤더에 "취소" 버튼 보임 → 클릭 → confirm → 약 1.5s 뒤 status=cancelled
5. agent 가 0개인 user (테스트용 별도 계정) 로 시도 → 폼 에러 메시지 "등록된 agent 없음"
