# 17. M2.10 — per-session `requirements` 자동 설치

- **상태**: 구현 착수 (2026-04-24)
- **이전 단계**: [16-m2.9-python-packages.md](16-m2.9-python-packages.md) + M2.9.1 patch
- **다음 단계**: M3.1 — 웹 대시보드 (Next.js)

## 목표

M2.9 번들에 포함된 4 패키지 (`pywinauto`/`pyautogui`/`selenium`/`mss`) 외에 사용자가 필요로 하는 임의의 Python 패키지를 세션 단위로 선언해 실행 시점에 자동 설치·사용할 수 있게 만든다.

M2.10 완료 조건:

- `session_snapshot.requirements: list[str]` 필드를 agent 가 해석.
- agent 가 `%APPDATA%\ohdo\packages\<sha256>\` 에 `pip install --target` 으로 설치 (콘텐츠 해시 캐시).
- 2번째 이후 같은 requirements 조합은 **캐시 히트** 로 즉시 진행.
- 설치 과정은 `execution.log` 에 `stream=engine` 으로 스트리밍 → 사용자가 WS/REST 로 관찰 가능.
- 설치 실패 시 `execution.result(status='failed')` + `error_summary` 에 사유.
- 스텝 코드 실행 시 `sys.path.insert(0, cache_dir)` 가 자동 prepend 되어 설치된 패키지 import 가능.
- 코어 회귀 25/25. **core 수정 0**.

## 설계 결정

| # | 항목 | 결정 |
|---|---|---|
| 1 | 저장 위치 | `%APPDATA%\ohdo\packages\<hash>\` (사용자별, 쓰기 권한 OK) |
| 2 | 캐시 키 | `sha256(sorted(requirements)).hexdigest()[:16]` — 입력 순서 무관, 동일 조합 = 재사용 |
| 3 | 설치 도구 | bundled embedded python 의 pip (`<embed_py> -m pip install --target=<cache_dir>`) |
| 4 | sys.path 주입 | `_BundleCodeSandbox.execute` 가 user code 앞에 `sys.path.insert(0, r"...")` 라인 prepend. `PYTHONPATH` env 는 멀티 실행 경쟁 우려로 회피 |
| 5 | 설치 로그 | `pip` 의 stdout/stderr 를 라인 단위로 `execution.log(stream="engine", step_id=null)` 송신 |
| 6 | 캐시 성공 마커 | `cache_dir/.ok` 파일 — 이게 있을 때만 "이미 설치됨" 인정 (중간 실패 시 재시도) |
| 7 | 설치 타임아웃 | 기본 120초. 초과 시 실패 처리 |
| 8 | 버전 constraint | `pip install` 에 그대로 전달 (`"requests>=2.30,<3"` 등 전부 유효) |

### 왜 sys.path.insert 방식인가

- `PYTHONPATH` 환경변수는 `os.environ` 을 통해 subprocess 에 전달 → 멀티 실행 동시 동작 시 race.
- `python.exe -m site` 확장도 `._pth` 수정이 필요해 이식성 나쁨.
- **subprocess 에 넘어갈 code 문자열 자체에 `sys.path.insert` 한 줄 prepend** 는 완전 격리되어 race-free. 가장 단순.

### 캐시 디렉터리 수명

- 삭제 정책 없음 (M2.10 에선). 누적되면 `%APPDATA%\ohdo\packages\` 가 커짐 — 일반적 RPA 워크플로 20~50 MB 선.
- 향후 GC: LRU 기반 cleanup task (M3+ 에서 검토).

## 구현

### `runner.py` 변경

```python
class _BundleCodeSandbox(CodeSandbox):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.extra_syspath: list[str] = []

    def _install_missing_packages(self, code):  # M2.9
        return None

    def execute(self, code, cwd=None, pre_exec_callback=None, post_exec_callback=None):
        if self.extra_syspath:
            prelude = "import sys\n" + "".join(
                f"sys.path.insert(0, {p!r})\n" for p in self.extra_syspath
            )
            code = prelude + code
        return super().execute(code, cwd=cwd,
                               pre_exec_callback=pre_exec_callback,
                               post_exec_callback=post_exec_callback)
```

```python
def _resolve_agent_appdata() -> Path:
    override = os.getenv("OHDO_APPDATA")
    if override:
        return Path(override)
    if sys.platform == "win32":
        base = os.getenv("APPDATA")
        if base:
            return Path(base) / "ohdo"
    return Path.home() / ".ohdo"
```

```python
class ExecutionRunner:
    def _ensure_requirements_installed(
        self, execution_id: str, requirements: list[str], log_buf: _LogBuffer,
    ) -> Path | None:
        """Content-addressed install. 빈 목록이면 None. 실패 시 예외."""
        normalized = sorted(r.strip() for r in requirements if isinstance(r, str) and r.strip())
        if not normalized:
            return None
        digest = hashlib.sha256("\n".join(normalized).encode()).hexdigest()[:16]
        cache_dir = _resolve_agent_appdata() / "packages" / digest
        marker = cache_dir / ".ok"
        if marker.is_file():
            log_buf.append(stream="engine", step_id=None,
                           line=f"requirements cache hit: {digest}")
            return cache_dir
        cache_dir.mkdir(parents=True, exist_ok=True)
        log_buf.append(stream="engine", step_id=None,
                       line=f"installing requirements (sha256={digest}): {', '.join(normalized)}")
        python_exe = _resolve_python_exe()
        cmd = [python_exe, "-m", "pip", "install",
               "--target", str(cache_dir), "--no-warn-script-location", *normalized]
        proc = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
                                text=True, encoding="utf-8", errors="replace")
        try:
            for raw in proc.stdout:
                line = raw.rstrip()
                if line:
                    log_buf.append(stream="engine", step_id=None, line=f"pip: {line}")
            rc = proc.wait(timeout=120)
        except Exception:
            proc.kill()
            raise
        if rc != 0:
            raise RuntimeError(f"pip install rc={rc}")
        marker.write_text("ok", encoding="ascii")
        log_buf.append(stream="engine", step_id=None,
                       line=f"requirements installed: {cache_dir}")
        return cache_dir
```

## Core 수정

**없음**. `CodeSandbox.execute` 를 서브클래스가 래핑. script 앞에 sys.path 주입은 core 접근 없음.

## 범위 밖

- 캐시 GC (수동 정리 문서화만)
- requirements 에 로컬 경로·git URL 허용 여부 (보안 검토 필요 → M3+)
- pip 외 poetry/uv 등 대체 해석기
- 설치 중 cancel 지원 (현재는 install 끝난 후에만 cancel 가능)
- sandboxed install (pip 자체의 보안 심사 없음)
